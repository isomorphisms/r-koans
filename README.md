# R koans

A collection of small R exercises, puzzles, and teaching sequences, organized by the people who designed them.

The goal here is not to erase provenance by blending everything into one anonymous tutorial. Each source gets its own folder, its own credit, and its own license notes. Where an exercise is copied or adapted, that is stated plainly. Where a source is only an inspiration, that is stated plainly too.

All executable koan sets in this repository should use **testthat edition 3** as the common testing framework.

## Sources

- **Colleen O'Briant teaches the tidyverse** — twenty progressive tidyverse koans originally designed for an upper-level econometrics course.
- **Patrick Burns leads you through The R Inferno** — a reading guide to Burns's catalog of R traps and surprises; the book itself is not reproduced here.

More source collections will be added with the same provenance-first structure.

## Reformatting

Some material is reformatted by ChatGPT / OpenAI for a uniform repository layout and testing interface. Reformatting does not transfer authorship of the underlying ideas, exercises, or prose. Each source folder says what was changed and who wrote or designed the original material.
