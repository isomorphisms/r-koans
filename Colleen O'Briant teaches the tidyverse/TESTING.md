# Testing

This source collection uses **testthat edition 3**.

That is both the repository-wide convention and the convention already used by Colleen O'Briant's upstream `tidyverse_koans` project.

The intended feedback loop is simple:

1. open a koan;
2. fill in one or more marked answers;
3. run the corresponding test file;
4. use the failure as feedback;
5. repeat until it passes.

The anthology may normalize paths and runner setup, but it should not silently rewrite the substance of O'Briant's questions merely to make them fit another testing style.
