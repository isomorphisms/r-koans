# Provenance

Upstream: <https://github.com/cobriant/tidyverse_koans>

Original author and exercise designer: **Colleen O'Briant**.

The upstream project is a twenty-koan teaching sequence for R/tidyverse work, originally designed for an upper-level econometrics course. The upstream tests use **testthat edition 3**.

This anthology copy was reorganized in **August 2026** by **ChatGPT / OpenAI** for `isomorphisms/r-koans`:

- author/source material is kept in its own folder;
- executable exercises use the repository-wide testthat edition 3 convention;
- file placement and runner plumbing may be changed to make different source collections look alike;
- underlying exercise ideas, pedagogical sequence, and copied/adapted text remain attributed to Colleen O'Briant.

Where an upstream file is copied verbatim, its content remains O'Briant's work. Where only formatting, paths, or test harness details are changed, those changes do not imply authorship of the exercise.
